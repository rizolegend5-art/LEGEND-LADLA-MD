## Features

### Pair-code dashboard
1. Enter a unique bot/session name.
2. Enter a WhatsApp number with country code.
3. Copy the generated pairing code into WhatsApp Linked Devices.

### After Connection
- Bot sends a connected message with the **LEGEND LADLA LEGEND LADLI MD** identity.
- Type **.menu** in WhatsApp to see the command list.
- `.roast` replies in Urdu.
- `.antistatus on/off` deletes status shares from groups when the bot is an admin.
- `.antisticker on/off` deletes stickers from groups.

## Railway deployment
Railway supplies `PORT` automatically. This bot binds to `0.0.0.0`, exposes `/api/health`, and serves the pair console at `/pair`. After deployment, open the Railway-generated service domain:

```text
https://YOUR-SERVICE.up.railway.app/pair
```

Set these Railway variables:

```text
OWNER_NUMBER=923154734548
DATA_DIR=/data
```

Replace `OWNER_NUMBER` with the full bot account number in digits. To keep the WhatsApp login after redeploys, create a Railway Volume mounted at `/data`. Without a persistent volume, the bot may need to be paired again after a restart.

### Important command and access rules
The bot now replies to commands only when the configured prefix is present. The default prefix is `.`; for example, use `.menu`, not `menu`. Normal messages without a prefix are ignored by the command router.

Commands sent from the bot account's own **Message yourself** chat are supported. Use `.menu` or `.owner` there after the linked device shows as connected. Normal non-command self messages are ignored to prevent loops.

Set `DEV_NUMBER` to the developer number in digits only. That number receives the same owner-level access even when the bot is in private mode. Keep `DEV_NUMBER` secret and do not publish it.

### Status protection
In a group where the bot has admin permissions, an admin can enable the requested protection with:

```text
.statusfuck on
```

Disable it with `.statusfuck off`. `.antistatus` remains an alias. WhatsApp delivers status updates as `status@broadcast`, so the protection can attempt deletion of statuses received by the connected bot account; WhatsApp permissions and message type determine whether deletion succeeds.

### Official channel
The bot does not silently follow a channel on behalf of newly connected users. Use `.channel` or `.followchannel` to receive the official channel link, then follow it voluntarily. Set `WHATSAPP_CHANNEL_URL` in Railway to configure the link.

Or with PM2:
```bash
npm install -g pm2
pm2 start ecosystem.config.js
```
