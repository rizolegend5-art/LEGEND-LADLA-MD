Professional WhatsApp Bot with a WhatsApp-only pair-code dashboard, live group protection, and Urdu fun commands.

## Features

### Pair-code dashboard
1. Enter a unique bot/session name.
2. Enter a WhatsApp number with country code.
3. Copy the generated pairing code into WhatsApp Linked Devices.

### After Connection
- Bot sends a connected message with the **LEGEND LADLA LEGEND LADLI MD** identity.
- Type **.menu** in WhatsApp to see the command list.
- `.roast` replies in Urdu.
- `.antistatus on/off` deletes status shares from groups when the bot is an admin.
- `.antisticker on/off` deletes stickers from groups.
